# План разработки Главы 2: «Город» — Мини-игра «Толпа» (HTML5)

---

## 📋 Общая информация

**Локация:** Город (лесной базар)  
**Цель:** Найти Лису в толпе антропоморфных животных  
**Формат:** 3 раунда с возрастающей сложностью  
**Условие победы:** Тапнуть по Лисе во всех трёх раундах  
**Условие проигрыша:** Не успеть тапнуть в раунде (перезапуск раунда)

---

## 🎯 Пошаговый план разработки

### Этап 1: Подготовка и дизайн (1–2 дня)

#### 1.1. Визуальные ассеты
- [ ] **Спрайты животных:** PNG/SVG спрайты для 30–40 видов антропоморфных животных (ежи, кабаны, белки, совы, медведи и др.) — размер ~64x64px, оптимизировано
- [ ] **Спрайт Лисы:** отдельный спрайт Лисы в красном платье (вид спереди, крупно) — ~128x128px для читаемости
- [ ] **Фон города/базара:** фоновый спрайт с крышами, лавками, деревьями (1920x1080, CSS `background-size: cover`)
- [ ] **UI элементы:** таймер (цифры), счётчик раундов, кнопка перезапуска — CSS + HTML
- [ ] **Ложные лисы (раунд 3):** рыжая кошка, белка в рыжей шубке — PNG/SVG

#### 1.2. Сценарий и диалоги
- [ ] **Кат-сцена перед главой:** Данич прибывает в город после «Тиндера» (комикс-кадр)
- [ ] **Текст кат-сцены:** описание перехода из леса в город, шутки о «цивилизации»
- [ ] **Подсказка при провале:** текст для 3 неудач подряд («Посмотри на рыжего!»)

#### 1.3. Настройка параметров
- [ ] **Раунд 1:** 25 животных, 20 сек, Лиса каждые 4 сек × 2 сек
- [ ] **Раунд 2:** 45 животных, 15 сек, Лиса × 1,5 сек, быстрее движение
- [ ] **Раунд 3:** 70 животных, 12 сек, Лиса × 1 сек, ложные лисы (рыжие кошки, белки)

---

### Этап 2: Реализация в HTML/JS (3–4 дня)

#### 2.1. Структура проекта
- [ ] **Создать `index.html`:**
  - [ ] Контейнер для фона города (`#game-container`)
  - [ ] UI холст с таймером и счётчиком раундов (`#ui-layer`)
  - [ ] Пустой контейнер для животных (через JS спавн)

- [ ] **CSS стили:**
  - [ ] Адаптивность под разные разрешения
  - [ ] Анимации появления/исчезновения (CSS transitions)
  - [ ] Эффекты: вспышка при попадании, вибрация при штрафе

#### 2.2. Игровой движок (JavaScript)

- [ ] **Основной цикл:** `requestAnimationFrame` для плавной анимации
- [ ] **Система движения животных:**
  - [ ] Объект `Animal` с координатами, скоростью, вектором движения
  - [ ] Случайные векторы скорости при спавне
  - [ ] Простая коллизия (отталкивание при пересечении) — проверка AABB или кругов

- [ ] **Система спавна:**
  - [ ] Функция `spawnAnimals(count)` для заполнения экрана
  - [ ] Лиса появляется в случайной позиции через интервал времени (`setTimeout`)
  - [ ] Лиса исчезает после таймера видимости (2/1.5/1 сек)

- [ ] **Обработка тапа:**
  - [ ] Pointer events на контейнере (`pointerdown`)
  - [ ] Raycast не нужен — проверка `elementFromPoint()` под координатами клика
  - [ ] Проверка: попали в Лису? → победа раунда
  - [ ] Штраф: попали в другое животное → −3 сек, животное «обижается» (добавляется в толпу)

- [ ] **Состояния игры:**
  - [ ] `Waiting` — ждём появления Лисы
  - [ ] `Active` — Лиса видна, игрок тапает
  - [ ] `Penalty` — штрафное время (визуальный эффект)
  - [ ] `RoundWin` — раунд пройден
  - [ ] `GameOver` — не успел, перезапуск

- [ ] **Раунды и сложность:**
  - [ ] Конфигурация в JS-объекте: `{ count, time, foxVisibilityTime, speedMultiplier }`
  - [ ] Автоматический переход между раундами при победе

- [ ] **Ложные лисы (раунд 3):**
  - [ ] Отдельные спрайты: рыжая кошка, белка в рыжей шубке
  - [ ] Различимы только по деталям (уши, хвост)

#### 2.3. Аудио
- [ ] **Музыка:** бодрый бит для города (Web Audio API или HTML5 `<audio>`)
- [ ] **SFX:**
  - [ ] Тап по животному: «ой!» (разные звуки для разных видов)
  - [ ] Лиса найдена: рыжий мотив (флейта, короткая мелодия)
  - [ ] Штраф: звук обиды («ух ты!»)

---

### Этап 3: Тестирование и полировка (1–2 дня)

- [ ] Проверить тайминги всех раундов
- [ ] Проверить штрафные механики

#### 3.3. Визуальная полировка
- [ ] Добавить лёгкие анимации появления/исчезновения Лисы (CSS)

### Этап 4: Кат-сцены и переходы (0.5 дня)

#### 4.1. Перед главой
- [ ] Комикс-кадр: Данич идёт из леса в город, смотрит на часы
- [ ] Текст: «А теперь — цивилизация! Лиса где-то здесь!»

#### 4.2. После победы
- [ ] Кат-сцена: Данич хватает Лису за лапу, она вырывается
- [ ] Диалог Лисы: «Последнее испытание, бородач!»
- [ ] Переход к Главе 3: кафе

## 📊 Технические требования

| Параметр | Значение |

| Видимость Лисы | 1–2 сек |

## 📝 Примечания

- Лиса не должна появляться подряд дважды в одном раунде
- Ложные лисы (раунд 3) должны быть визуально отличимы при внимательном рассмотрении
- Все животные из общего пула, чтобы не перегружать память
